Nebula SDK

A metadata-driven memory SDK for Hill Climb Racing 2, built for GameGuardian's Lua environment. Every field is a dotted path — resolved against versioned struct metadata.

Get Started View on GitHub
Lua 
local Nebula = dofile("/sdcard/nebula/nebula-1.0.0")

-- typed, declarative reads and writes
local coins = Nebula.PlayerInfo.get("gameStatus.coins")
Nebula.PlayerInfo.set("gameStatus.playerName", "Hillbilly")

-- verify the write actually landed in memory
Nebula.PlayerInfo.set("gameStatus.coins", 999):verify()
metadata-driven
Fields are declared once — offset, type, container ABI — and versioned per game release (1.73, 1.74 snapshots).
One dotted path model
Child structs, array indexing, repeated elements — all one path syntax resolved by core/Path.lua.
A guest in your script
Loads without touching your globals. One exported table, merge-tolerant, enforced by its own spec.
300 spec checks
Mock-driven test suite covering the API surface, array/trace machinery, and the packed artifact.
